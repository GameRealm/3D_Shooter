#  PyroProtocol

A fast-paced third-person shooter set in a training simulator, where the focus is on movement and aiming at targets. 

## 🎮Play
[Play on itch.io] [link](https://historyloom.itch.io/pyroprotocol)

## Core Idea
Keep moving and react quickly to hit as many targets as possible in a semi-open environment.
The game places a strong emphasis on mobility, target prioritization, and quick reflexes. 

## Features

- Semi-open combat space for free movement
- Target-based shooting with varied behaviors
- Stylized fireball shooting effects

## Controls

- WASD — movement
- Mouse — aim
- LMB — shoot

## How to Play

Download the build and run the .exe file.

## Status

Prototype 

## What I focused on

- Responsive shooting feel
- Clear player feedback
- Encouraging player decision-making
